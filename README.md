# 🖥️ COBOL & Mainframe Backend Portfolio

Welcome to my COBOL development repository. This project serves as a portfolio of my practical learning, structured business logic implementation, and legacy environment simulation.

---

## 🛠️ Technologies & Concepts Covered
* **Language:** Enterprise COBOL
* **Mainframe Tools:** JCL (Job Control Language)
* **Core Concepts:** File handling (sequential & indexed), Batch processing, System logic, Data structures, Mainframe environment simulations (DB & CICS basics).

---

## 📂 Repository Structure

The code is organized into specific domain modules to reflect real-world mainframe architecture:

* **`basics/`**: Fundamental algorithms, mathematical calculations, and control structures.
* **`files/`**: Sequential and indexed file processing, input/output operations, and report generation.
* **`batch/`**: Batch processing logic and structured data manipulation.
* **`Jcl/`**: Job Control Language scripts used to execute batch programs in mainframe environments.
* **`db-sim/`**: Simulations of database interaction logic and data persistence.
* **`cisc-sim/`**: Transactional logic simulations based on CICS application frameworks.

---

## 💻 Environment & Setup
* Programs tested and compiled using **GnuCOBOL** (OpenCOBOL) on UNIX/Linux environments via WSL2.
* Code formatted using standard COBOL reference format.
